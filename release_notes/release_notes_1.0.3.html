Version 1.0.3 Update

January 11, 2026

New Features

  • To-do List: Introducing a sleek To-do List feature. Now you can manage your tasks effectively while listening to music.
  • Minimal Menubar UI: The menubar popover has been redesigned with a more intuitive and minimal interface.
  • Waveform Visualization: Experience dynamic audio waveforms displayed at the top while playing music.
  • Menubar Timer: Added a timer feature accessible directly from the menubar to help you track remaining time.
  • Audio Output Selection: You can now choose your preferred audio output device, such as speakers or headphones.

Improvements & Fixes

  • Enhanced Playback Controls: Volume control and playback seeking (Seek) are now more precise.
  • Layout Optimization: Improved track list scroll behavior and overall layout stability.
  • Bug Fixes: Resolved memory leak issues during timer execution and fixed app re-launch initialization warnings.
  • UI Polishing: Refined the Black & White theme for better consistency across the entire app.
Thank you for using Rytmo.
